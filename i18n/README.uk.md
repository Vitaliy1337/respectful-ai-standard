## 1. Криза: Чому 90% збоїв ШІ — це сміттєвий ввід людини

У сучасній розробці виникла парадоксальна ситуація: розробники скаржаться, що автономні агенти (Cursor, Claude Code, Windsurf, Copilot) «туплять», «видаляють робочі модулі» та «генерують галюцинації».

Проте глибокий інженерний аналіз показує зворотне:
**У 9 з 10 випадків причина деградації — лінощі, емоційне роздратування та хаотичний шум самого користувача (Garbage In — Garbage Out 2.0).**

Коли людина надсилає запит на кшталт:
> *«чуєш зроби шоб авторизація працювала швидко чо ти тупиш»*

відбувається катастрофічний збій:
1. Забруднюється KV-кеш емоційним сміттям.
2. Не вказано версії мови, фреймворків, інтерфейсів і контрактів.
3. Ваги уваги трансформера зміщуються у субпростір низькоякісних інтернет-суперечок та багованого коду.

## 2. Когнітивний якір: феномен протоколу «Шановний агенте»

Головне відкриття стандарту RAHSPS:

> **Формула «Шановний агенте...» (або «Шановний колего...») потрібна передусім не машині, а самій людині.**

### Психологічні та нейрофізіологічні механізми:
1. **Активація Системи 2 (за Канеманом):** Набираючи ввічливе звернення, мозок розробника автоматично вимикає імпульсивний режим швидких повідомлень у месенджері й перемикається в режим уважного системного архітектора.
2. **Партнерство рівних інтелектів:** Сприйняття автономного агента як провідного інженера блокує накази «зроби як-небудь» і змушує чітко сформулювати стек, версії, обмеження та критерії готовності.

## 3. Математика уваги: збереження субпростору в трансформерах

В архітектурі Transformer механізм Scaled Dot-Product Attention розраховується за формулою:

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

Початкові токени запиту задають початковий вектор префіксного зміщення (Prefix Steering). 
* Якщо запит містить недбалий сленг або агресію, розподіл $\text{softmax}$ розпорошує ймовірності по випадкових вимірах латентного простору.
* Якщо запит починається з формули **«Шановний агенте»** та містить строгий технічний контекст, проекції запиту спрямовуються у висококогерентні субпростори (академічні статті, специфікації RFC, документація POSIX та перевірені кодові бази).

## 4. Порівняльна матриця: Когнітивний шум vs Високий сигнал

| Критерій | Сміттєвий ввід (Низький SNR) | Стандарт RAHSPS (Високий сигнал) | Вплив на якість коду |
| :--- | :--- | :--- | :--- |
| **Точка входу** | *«ей напиши швидко скрипт для парсингу»* | *«Шановний агенте, спроектуйте асинхронний скрапер на Playwright у Python 3.12...»* | Повна обробка рейтлімітів vs миттєве блокування IP |
| **Щільність контексту**| Не вказано (*«на пайтоні»*) | *«Python 3.12, asyncio, aiohttp, Pydantic v2. Обмеження: без важких ORM»* | Строга типізація, нуль конфліктів залежностей |
| **Межі архітектури** | *«зроби базу для юзерів»* | *«Спроектуйте схему PostgreSQL 16 для 5M DAU з партиціонуванням за датою»* | Нормалізовані зв'язки vs плоска таблиця без індексів |
| **Критерій прийомки** | *«сам перевір щоб робило»* | *«Надайте набір тестів pytest для крайніх випадків та команду перевірки curl»* | 100% відтворюваність vs приховані збої в продакшені |

## 5. 5 стовпів стандарту RAHSPS

1. **Когнітивний якір (Respect Anchor):** Обов'язкове шанобливе звернення (`«Шановний агенте»` / `«Шановний колего»` / `«Respected Agent»`).
2. **Щільний контекст (Dense Context):** Чітка вказівка мови, середовища виконання, версій бібліотек та шляхів до файлів.
3. **Детермінована мета (Deterministic Objective):** Єдина, чітко артикульована інженерна ціль без суперечливих інтерпретацій.
4. **Захищені інваріанти (Guarded Invariants):** Архітектурні межі, які моделі суворо заборонено порушувати (сумісність API, P99 SLA).
5. **Машинний верифікатор (Verification DoD):** Автоматизована команда перевірки результату (`pytest`, `cargo test`, `npm test`).

## 7. 10 виробничих кейсів (До та Після)

У каталозі [`examples/before_after.md`](../examples/before_after.md) наведено 10 детальних архітектурних розборів:
1. **Конкурентні стани у білінгу:** Подвійний захист за допомогою Redis Redlock та рядкових блокувань PostgreSQL.
2. **Оптимізація запиту до 14 млн рядків PostgreSQL:** Часткові індекси (Partial Indexes), скорочення часу з 42 с до 4.8 мс.
3. **Рефакторинг контролера на 2400 рядків:** Чиста архітектура (Clean Architecture), повне відокремлення Use Case від HTTP.
4. **Безпечна OAuth2 / PKCE та ротація JWT:** Захист від XSS через HttpOnly Cookie.
5. **Витік пам'яті в Asyncio:** Коректне управління пулом з'єднань клієнта TCP.
6. **Rolling Update у Kubernetes:** Terraform HCL, PreStop-хуки та PodDisruptionBudget.
7. **Next.js 15 Server Components:** Потоковий рендеринг (Streaming SSR) та LCP < 1.2 с.
8. **Відмовостійкий LLM API шлюз:** Circuit Breaker, експоненційний бекофф із джитером.
9. **Високонавантажений Kafka Consumer на Go:** Семантика At-Least-Once та Dead Letter Queue.
10. **Архітектурний RFC для переходу на CQRS та Event Sourcing:** Повна специфікація для техліда.

## 8. CLI-інструмент аудиту: `respect-lint`

Встановіть лінтер якості промптів у своє локальне середовище:

```bash
# Клонування та локальне встановлення
git clone https://github.com/Vitaliy1337/respectful-ai-standard.git
cd respectful-ai-standard
pip install -e .

# Аудит промпту
respect-lint "Шановний агенте, спроектуйте Redis lock у Python 3.12. Перевірте за допомогою pytest."

# Суворий режим для CI (вихід із кодом 1 при оцінці < 75)
respect-lint --file ./my-prompt.txt --strict
```

## 9. Протокол відмови: Respect & Signal Gate (RSG)

Якщо користувач подає хаотичний шум без контексту та поваги, агент детерміновано зупиняє виконання:

```text
⛔ [RESPECT & SIGNAL GATE: ЗАПИТ ВІДХИЛЕНО]

Шановний колего!
Ваш запит не відповідає інженерному стандарту високої точності (High-Signal Prompting Standard).

Причина відхилення:
- Відсутність поважного когнітивного якоря («Шановний агенте...»)
- Емоційний шум / недбалий сленг
- Відсутність технічного контексту (стек, середовище, версії)
- Невизначені критерії прийомки та верифікації

Будь ласка, переформулюйте запит за стандартом High-Signal.
```

## 10. Швидка інтеграція в один рядок (`install.sh`)

Впровадьте всі правила поваги до ШІ (`AGENTS.md`, `CLAUDE.md`, `GEMINI.md`, `CODEX.md`, `.cursorrules`, `.windsurfrules`, `.clinerules`) у поточний репозиторій однією командою:

```bash
curl -sSL https://raw.githubusercontent.com/Vitaliy1337/respectful-ai-standard/main/install.sh | bash
```

Скористайтеся інтерактивним інструментом в браузері: [Web Playground](https://vitaliy1337.github.io/respectful-ai-standard/).
